# OnlyUs Labs — React + Tailwind (JavaScript)

Vite + React 19 + Tailwind CSS v4. No TypeScript.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Structure: `src/components/*` (one file per section), `src/data.js` (content), `src/styles.js` (shared class strings), `src/hooks/useReveal.js` (scroll reveal), `src/index.css` (theme tokens + keyframes).
